# Project instructions

Never run `git` with the user's home directory as the working directory or target that directory directly with `git -C`.

Follow `$HOME/.codex/RTK.md` when available. It requires prefixing shell commands with `rtk` (use `rtk proxy` for commands without a dedicated wrapper).

## Privacy

This repository is public. Never put private deployment details in tracked files, examples, tests, commit messages, or other public material. This includes real hostnames, addresses, usernames, provider choices, paths, topology, credentials, and user content. Use fictional placeholders under reserved domains such as `example` and `example.com`. Keep private operational details outside the repository. Review changes for private data before sharing them.
